# IT 设备与信息安全管理制度

## 第一章 总则

1.1 为规范公司 IT 资产管理与信息安全管理，保障业务数据安全，制定本制度。

1.2 本制度适用于公司全体员工的办公设备使用及信息系统操作行为。

## 第二章 设备领用与归还

2.1 新员工入职由 IT 部统一配发办公电脑（默认 ThinkPad T14），入职当天凭入职单领取。

2.2 领用设备需在 IT 资产系统登记，员工对领用设备负有保管责任。

2.3 员工离职须在离职交接日归还全部 IT 设备，由 IT 部核验设备完好并注销账号。

2.4 设备损坏或遗失：人为损坏按维修成本赔偿，遗失按设备折旧净值赔偿；因公出差期间被盗的，凭报案回执可减免。

## 第三章 账号与密码安全

3.1 企业邮箱、OA、钉钉等系统账号实行实名制，一人一号，禁止转借他人使用。

3.2 密码设置须满足：长度不少于 10 位，包含大小写字母、数字和特殊字符中的至少三类。

3.3 密码须每 90 天更换一次，禁止将密码记录在便签贴在工位上。

3.4 员工离职或转岗，IT 部须在当日冻结或调整其系统权限。

## 第四章 网络安全

4.1 公司办公网络统一通过企业 WiFi 接入，个人设备访客网络仅限临时使用。

4.2 禁止私自在办公网络内搭建无线热点、连接未经授权的 VPN。

4.3 访问互联网须遵守公司网络管理规定，禁止下载安装盗版软件及来路不明的程序。

4.4 涉及重要数据的传输必须使用公司加密通道。

## 第五章 数据安全

5.1 公司数据分为公开、内部、机密三级：内部及以上数据禁止外发至个人网盘、私人邮箱。

5.2 客户资料、合同、财务报表、源代码等机密数据须加密存储，访问需申请授权。

5.3 员工禁止将公司数据用于与工作无关的用途，离职时须归还全部数据载体。

5.4 重要文件建议每日备份至公司云盘，本地磁盘故障不承担数据找回义务。

## 第六章 软件与正版化管理

6.1 办公软件由 IT 部统一采购安装，员工不得私自安装与工作无关的软件。

6.2 确需安装特殊软件的，须向 IT 部提交申请，经安全评估后方可安装。

6.3 禁止使用破解软件、盗版系统，一经发现立即卸载并按公司纪律处理。

## 第七章 安全事件报告

7.1 发现病毒、木马、钓鱼邮件或可疑访问行为的，须第一时间断开网络并报告 IT 部。

7.2 发生数据泄露事件的，须在 1 小时内报告 IT 部与部门负责人，隐瞒不报的从严处理。

7.3 IT 部定期组织信息安全培训与钓鱼邮件演练，全员须参加。

## 第八章 附则

8.1 本制度由 IT 部制定并负责解释，自发布之日起施行。

8.2 违反本制度的，视情节给予警告、扣发绩效直至解除劳动合同的处理，造成公司损失的依法追偿。
