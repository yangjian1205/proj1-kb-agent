# 招聘与入职管理制度

## 第一章 总则

1.1 为规范招聘流程，确保招聘质量与效率，制定本制度。

1.2 本制度适用于公司各岗位的社会招聘、校园招聘与内部推荐。

## 第二章 招聘需求与审批

2.1 部门提出用人需求须填写《招聘需求表》，说明岗位职责、任职要求、编制情况与到岗时间。

2.2 招聘需求审批：普通员工由部门负责人与人事行政部审批，主管及以上岗位须分管副总与总经理审批。

2.3 招聘遵循"先内后外"原则，优先考虑内部转岗与员工推荐。

## 第三章 招聘渠道与流程

3.1 主要招聘渠道：BOSS 直聘、拉勾网、猎聘、公司官网与内部推荐。

3.2 面试流程：简历筛选 → 用人部门初试 → 交叉面试/复试 → 终试（主管及以上岗位）→ 背景调查 → 薪酬沟通 → 发放 Offer。

3.3 面试官须提前阅读简历并准备结构化问题，面试评价表须当日完成填写。

3.4 内部推荐奖励：推荐人选成功入职且通过试用期的，推荐人可获得 1000-5000 元推荐奖金（视岗位级别）。

## 第四章 录用与背调

4.1 Offer 发放前须完成学历、上家单位离职证明等背景核实。

4.2 涉及财务、采购等敏感岗位须增加前雇主背调环节。

4.3 Offer 审批：普通员工由人事行政部负责人审批，主管及以上由总经理审批。

4.4 Offer 有效期 7 个自然日，逾期未确认视为放弃。

## 第五章 入职办理

5.1 员工入职当天携带身份证、学历学位证书原件、离职证明、体检报告、银行卡复印件至人事行政部报到。

5.2 人事行政部办理入职手续：签订劳动合同（首次签订 3 年，试用期 3-6 个月）、签署保密协议、录入考勤系统、领取办公用品。

5.3 新员工入职当天由 IT 部开通账号并配发办公设备，由用人部门安排工位并指定入职导师。

5.4 入职首日安排公司简介、制度培训及部门介绍，试用期第 1 周内完成岗位技能培训计划制定。

## 第六章 试用期管理

6.1 试用期 3-6 个月（含），试用期工资不低于转正工资的 80%。

6.2 试用期考核在试用期结束前 15 天启动，合格者按期转正，不合格者可延长试用期（累计不超过法定上限）或解除劳动合同。

6.3 试用期内员工可提前 3 天提出离职，公司也可依法解除劳动关系。

## 第七章 附则

7.1 本制度由人事行政部制定并负责解释，自发布之日起施行。

7.2 招聘过程中严禁就业歧视，遵循平等、择优原则。
