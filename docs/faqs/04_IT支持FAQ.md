# IT 支持 FAQ

## 一、账号登录

Q1：钉钉登录不上怎么办？
A：先试"忘记密码"手机号重置 → 仍不行联系 IT 服务台（内线 1234），IT 核实身份后重置。

Q2：企业邮箱密码忘了？
A：通过邮箱登录页"忘记密码"→ 手机验证重置；客户端收发信使用专用授权码（设置里生成），非登录密码。

Q3：OA 系统登录异常？
A：确认网络为办公 WiFi → 清理浏览器缓存 → 换 Chrome/Edge 重试 → 仍异常提工单。

Q4：WiFi 怎么连？密码多少？
A：连接"XX-Office"，账号工号，初始密码身份证后 6 位，登录后建议在自助页面修改；访客网络问前台要密码。

## 二、电脑与外设

Q5：电脑卡顿/死机怎么办？
A：先重启 → 清理 C 盘（剩余低于 10GB 易卡顿）→ 关闭开机自启多余程序 → 仍卡提工单检测（可能需加内存/换硬盘）。

Q6：想申请双屏显示器？
A：IT 服务台提交"外设申请"，公司标配 24 寸，3 个工作日内安装。

Q7：电脑坏了可以换吗？
A：设备故障先维修；在职满 3 年或维修成本过高可申请换机，IT 协助数据迁移。

Q8：键盘鼠标坏了去哪领？
A：IT 服务台直接领取标准型号，无需审批；特殊型号需部门负责人审批。

Q9：可以自己带电脑上班吗（BYOD）？
A：可以，但须先让 IT 安装公司安全软件并登记，否则无法访问公司内网资源。

## 三、软件与安装

Q10：想装某个软件怎么申请？
A：先查公司软件库（飞书/WPS/VS Code/JetBrains/Navicat/Xshell 等）——库内直接申请；库外提交"软件安装申请"由 IT 安全评估。

Q11：可以装破解软件吗？
A：不可以。使用破解/盗版软件违反《IT 设备与信息安全管理制度》，且易植入病毒，一经发现立即卸载并处理。

Q12：需要管理员权限装软件？
A：提交软件申请由 IT 统一评估安装，不向员工开放本机管理员权限（安全需要）。

## 四、网络与打印

Q13：打印机连不上？
A：确认连接办公 WiFi（访客网络无法打印）→ 检查打印机状态（卡纸/缺墨/离线路由器）→ 重新添加打印机（IT 已推送共享打印机，添加时选"XX-Print-楼层"）。

Q14：网速慢/断网？
A：先重启路由器/网卡 → 换网线或换 WiFi 频段（5G 优先）→ 仍异常提"网络故障"工单，IT 30 分钟内响应。

Q15：出差在外怎么访问公司内网？
A：通过公司 VPN（客户端在公司软件库下载），账号与 OA 一致；使用前确认已安装最新版本，禁止私搭其他 VPN。

## 五、数据与安全

Q16：重要文件放哪安全？
A：公司云盘（飞书云文档/企业网盘），本地硬盘故障不承担找回义务；机密文件加密存放。

Q17：收到钓鱼邮件怎么办？
A：不点链接不回复，立即转发至 it-security@example-corp.com 并删除；IT 会通报全员。

Q18：怀疑电脑中毒了？
A：立即断网 → 拔网线/关 WiFi → 联系 IT 服务台，不要自行杀毒或重启（可能清除证据）。

Q19：可以往个人 U 盘拷贝公司资料吗？
A：内部及以上数据禁止拷贝至个人设备；确有工作需要向部门负责人申请，经 IT 审批开通临时权限。

## 六、报修与时效

Q20：IT 问题怎么最快找到人？
A：钉钉"IT 服务台"提工单（留联系方式）→ 紧急故障（断网影响业务）直接内线 1234。

Q21：IT 响应要多长时间？
A：紧急 30 分钟内响应；普通请求 2 小时响应、4 小时给方案；复杂问题会给处理计划与预计完成时间。
