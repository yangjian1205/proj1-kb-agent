# 采购申请操作指南

## 一、采购范围与原则

1.1 本指南适用于公司非 IT 类的采购需求：办公用品、市场物料、服务采购（印刷、设计、活动）、固定资产等。

1.2 采购遵循"先审批、后采购"原则，未经审批的采购费用不予报销。

1.3 IT 类采购（电脑、软件、服务器等）走 IT 服务台流程，不适用本指南。

## 二、采购申请流程

2.1 提交：OA → 采购申请 → 填写采购物品名称、规格型号、数量、预估单价、用途说明、期望到货日期。

2.2 审批权限：
- 单笔 5000 元以内：部门负责人审批
- 单笔 5000-20000 元：部门负责人 + 行政/采购负责人审批
- 单笔 20000 元以上：须附 3 家供应商比价单，报总经理审批

2.3 审批通过后由采购部/行政部统一执行采购，申请人无需自行下单。

2.4 紧急采购（影响业务运营）：可先电话请示部门负责人后自行购买（单笔限 1000 元内），3 个工作日内补办采购申请。

## 三、供应商选择

3.1 常规品类（办公用品、印刷）使用公司合格供应商名录，行政部每半年更新一次。

3.2 单笔 20000 元以上采购须询价比价：至少 3 家供应商报价，填写《比价单》随申请提交。

3.3 新增供应商须提供营业执照、开户许可、样品（如需），行政部审核入库。

## 四、收货与验收

4.1 货物到货由申请人/使用人验收，核对品名、数量、规格与订单一致。

4.2 验收不合格：拍照留证，48 小时内联系行政部退换货。

4.3 验收合格后：申请人在 OA 采购单确认"验收通过"，行政部凭验收记录安排付款。

## 五、费用归属

5.1 采购费用计入申请部门预算，发票抬头为公司全称。

5.2 固定资产类采购（单价 2000 元以上、使用超 1 年）到货后由行政部登记资产标签。

5.3 采购发票当月提交财务，跨月按报销时限处理。

## 六、常见问题

6.1 Q：想买的物品公司名录里没有怎么办？A：在申请单备注"非名录商品"，采购部会单独询价；量大或长期需求可建议行政部纳入名录。

6.2 Q：自己先垫钱买了能报吗？A：已审批的采购由公司统一付款；确需个人垫付的（如紧急采购），凭发票+审批单报销，1-2 周内到账。

6.3 Q：采购到货时间一般多久？A：常规办公用品 3-5 个工作日；定制物料 7-15 天；具体以采购部反馈为准。
