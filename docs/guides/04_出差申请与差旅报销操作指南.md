# 出差申请与差旅报销操作指南

## 一、出差前申请

1.1 钉钉 → 工作台 → OA 审批 → "出差申请"，填写：出差事由、目的地、开始/结束日期、预计行程安排（交通方式、住宿需求）。

1.2 审批权限：3 天以内部门负责人；3 天以上分管副总；跨省/出国总经理审批。

1.3 审批通过后系统生成出差单号，预订机票/酒店请使用公司差旅平台（携程商旅企业版，工号登录），可享受协议价并由公司统一月结，无需个人垫付。

1.4 需差旅借款的：出差单审批通过后，在 OA"借款申请"中关联出差单申请借款（不超过预估 80%，上限 5000 元），财务 1-2 个工作日打款。

## 二、出差中注意事项

2.1 保留全部票据：登机牌、高铁票、住宿发票、打车发票；电子发票保存电子版。

2.2 行程变更（延期/改道/取消）及时在 OA 更新出差单并重新提交审批，否则可能影响报销。

2.3 住宿超标（一线城市超 500 元/晚，其他城市超 350 元/晚）须事前邮件报备部门负责人+财务，报销时附审批邮件。

2.4 出差期间如遇客户招待等额外费用，单独记录，回司后按"业务招待费"另行报销。

## 三、回司后报销

3.1 出差结束后 10 个工作日内提交差旅报销：OA → 费用报销 → 选择"差旅报销"→ 关联出差单号。

3.2 逐笔填写交通费、住宿费、市内交通，系统按出差天数自动计算伙食补助（一线城市 100 元/天，其他 80 元/天）。

3.3 上传票据影像：高铁票/机票行程单、住宿发票、市内交通发票。

3.4 借款冲销：有差旅借款的，报销单审批通过后系统自动冲销借款，多余应退金额将在打款时扣除，不足部分随报销款补发。

## 四、差旅常见问题

4.1 Q：出差期间逢周末怎么算？A：周末如需继续工作算加班（提前在出差单备注并走加班审批）；纯休息不算出差补助。

4.2 Q：飞机晚点/取消改签费用能报吗？A：非个人原因（天气/航司原因）产生的改签费、住宿费可凭航司证明报销。

4.3 Q：出差打车标准？A：优先公共交通；携带公司物品不便、夜间 22:00 后或紧急事务可打车，凭发票实报实销。

4.4 Q：出差回来当天直接回家，第二天再到公司可以吗？A：出差结束日（返程当天）算出差，次日需正常到岗；如想顺路回家休假，需另行申请休假。
