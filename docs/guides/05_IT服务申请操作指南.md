# IT 服务申请操作指南

## 一、IT 服务台入口

1.1 所有 IT 请求通过钉钉 → 工作台 → "IT 服务台"提交工单，或发邮件至 it@example-corp.com。

1.2 紧急故障（断网影响业务、系统无法登录）可拨打内线 1234 或直接到 4F IT 办公室。

1.3 工单响应时效：紧急故障 30 分钟内响应，普通请求 2 小时内响应，4 小时内给出处理方案。

## 二、常用申请类型

### 2.1 新设备申请（入职/换机）
- 入职电脑由 HR 提前通知 IT 配置，入职当天发放。
- 换机申请：在职满 3 年或设备故障可申请更换，在 IT 服务台提交"换机申请"，3 个工作日内完成数据迁移。

### 2.2 外设申请（显示器/键鼠/扩展坞）
- 外接显示器（双屏）：提交"外设申请"，注明尺寸偏好（公司标配 24 寸，特殊需求说明理由），3 个工作日内安装。
- 键鼠/扩展坞/耳机：标准型号仓库直接发放，特殊型号需部门负责人审批。

### 2.3 软件安装申请
- 公司软件库（飞书、WPS、VS Code、JetBrains 全家桶、Navicat、Xshell 等）内的软件可直接申请安装。
- 库外软件：提交"软件安装申请"，注明用途，IT 安全评估后 2 个工作日内回复；禁止私自安装破解软件。

### 2.4 账号与权限申请
- 新系统账号：提交"账号申请"，注明系统名称、所需权限，按权限审批链（申请人 → 部门负责人 → 系统管理员）审批。
- 权限变更/回收：转岗、离职由 HR 系统自动触发权限变更流程。

### 2.5 网络与打印
- WiFi 密码重置、有线网络故障：提交"网络故障"工单。
- 打印机添加/维修：提交"打印服务"工单，注明所在楼层与打印机编号。

## 三、常见自助处理

3.1 钉钉/飞书无法登录：先确认密码是否正确 → 忘记密码可点击"忘记密码"通过手机号重置 → 仍失败联系 IT 服务台。

3.2 邮箱无法收发：检查是否超过容量（清理后重试）→ 确认客户端密码是否为专用授权码 → 仍异常提工单。

3.3 电脑卡顿：先重启释放内存 → 清理 C 盘空间（C 盘剩余低于 10GB 易卡顿）→ 仍卡顿提工单检测硬盘/加内存。

3.4 无法连接打印机：确认连接的网络是否为办公 WiFi（访客网络无法打印）→ 检查打印机是否报错（卡纸/缺墨）→ 重新添加打印机。

## 四、IT 设备使用规范

4.1 电脑为公司资产，禁止私自拆机、改装、重装系统；确需重装的由 IT 统一处理。

4.2 禁止在公司电脑安装个人用途的 P2P 下载软件、游戏。

4.3 重要工作文件请每日备份到公司云盘（个人电脑硬盘故障不承担数据找回义务）。

4.4 员工离职时 IT 回收全部设备并清除本地数据，请提前备份个人工作文件。
