# 用印与合同管理流程指南

## 一、印章使用范围

1.1 公司印章包括：公章、合同专用章、财务专用章、发票专用章、法人章、部门章。

1.2 公章使用范围：对外文件、证明、授权委托书、政府报送材料等。

1.3 合同专用章：仅用于对外签署的各类合同、协议。

1.4 财务专用章、发票专用章：由财务部保管，用于财务票据及银行事务。

## 二、用印申请流程

2.1 OA → 用印申请 → 选择印章类型、填写用印文件名称、份数、用途、用印对象。

2.2 上传用印文件扫描件或清晰照片，审批人核对文件内容。

2.3 审批权限：
- 部门内部文件用印（部门章）：部门负责人审批
- 公章、合同章：部门负责人 + 行政部复核 + 分管副总审批
- 涉及对外担保、投资、重大资产处置等重大事项：须总经理审批

2.4 审批通过后持纸质文件原件到行政部（4F）用印，用印后登记台账。

2.5 用印文件须与审批时上传版本一致；不一致的行政部有权拒绝用印。

## 三、合同签订流程

3.1 合同由业务部门起草（使用公司标准模板的优先），填写《合同审批单》。

3.2 合同审批链：业务部门负责人 → 法务（如有）→ 财务（涉及付款条款）→ 分管副总 →（重大合同）总经理。

3.3 审批通过后用合同专用章签署，合同双方各执原件，公司原件由行政部归档。

3.4 合同电子版同步归档至公司合同管理系统，便于查询与续签管理。

## 四、用印注意事项

4.1 严禁在空白纸张、空白合同、空白介绍信上用印。

4.2 严禁携带印章外出；确需外带的（如外出签合同），须总经理书面批准并两人同行（一名为行政部人员）。

4.3 印章遗失须立即报告行政部并登报声明作废，追究保管人责任。

## 五、常见问题

5.1 Q：个人收入证明/在职证明盖章找谁？A：HR 开具后到行政部盖公章，流程：OA 用印申请（用途选"个人证明"）→ 行政部盖章，当天可取。

5.2 Q：合同想先盖章再走流程行吗？A：不行，一律先审批后用印；倒签合同的须在审批单备注"合同已签署，补办审批"并经分管副总同意。

5.3 Q：电子章可以用吗？A：公司已启用电子签章（法大大），标准合同优先走电子签，效力与实体章等同。
